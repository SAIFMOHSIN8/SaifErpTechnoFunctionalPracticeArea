2. NAVIGATE TO:
   SYSTEM ADMINISTRATOR --> SECURITY --> USER --> DEFINE

3. CREATE A NEW USER WITH THE FOLLOWING DETAILS:
   USER NAME: SAIF
   PASSWORD: CONFIGURED SECURELY
   EFFECTIVE FROM: 08-SEP-2026
   STATUS: ACTIVE

4. OPEN THE DIRECT RESPONSIBILITIES SECTION.

5. ASSIGN THE REQUIRED RESPONSIBILITIES:
   APPLICATION DEVELOPER
   SAIF_RESP_OMAN
   SYSTEM ADMINISTRATOR

6. CONFIRM THAT EACH RESPONSIBILITY HAS A VALID EFFECTIVE FROM DATE.

7. SAVE THE USER RECORD USING CTRL + S.

8. LOG OUT AND LOG BACK IN WITH THE NEW USER TO VERIFY ACCESS.
