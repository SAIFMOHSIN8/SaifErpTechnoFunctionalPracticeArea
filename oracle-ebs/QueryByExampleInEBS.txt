-- QUERY BY EXAMPLE IN ORACLE EBS --

1. LOG IN TO ORACLE E-BUSINESS SUITE.

2. NAVIGATE TO:
   SYSTEM ADMINISTRATOR --> SECURITY --> USER --> DEFINE

3. PRESS F11 TO ENTER QUERY MODE.

4. ENTER THE SEARCH VALUE IN THE REQUIRED FIELD:
   USER NAME: SAIF

5. PRESS CTRL + F11 TO EXECUTE THE QUERY.

6. REVIEW THE RETURNED USER RECORD.

7. CONFIRM THAT THE USER STATUS, EFFECTIVE DATES, AND ASSIGNED RESPONSIBILITIES ARE DISPLAYED.

8. TO PERFORM A PARTIAL SEARCH, USE THE % WILDCARD:
   %SAIF%

9. PRESS F4 TO CANCEL QUERY MODE IF REQUIRED.
