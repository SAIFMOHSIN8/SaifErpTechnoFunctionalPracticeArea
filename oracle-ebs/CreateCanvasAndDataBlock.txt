-- CREATE CANVAS AND DATA BLOCK IN ORACLE FORMS BUILDER --

1. OPEN ORACLE FORMS BUILDER.

2. CREATE A NEW FORM MODULE.

3. IN OBJECT NAVIGATOR, SELECT DATA BLOCKS.

4. OPEN THE DATA BLOCK WIZARD.

5. SELECT TABLE OR VIEW AS THE DATA SOURCE TYPE.

6. SELECT THE EMP DATABASE TABLE.

7. ADD THE REQUIRED EMP TABLE COLUMNS:
   EMPNO
   ENAME
   JOB
   MGR
   HIREDATE
   SAL
   COMM
   DEPTNO

8. COMPLETE THE DATA BLOCK WIZARD TO CREATE THE EMP DATA BLOCK.

9. OPEN THE LAYOUT WIZARD.

10. SELECT THE EMP DATA BLOCK ITEMS TO DISPLAY.

11. CREATE A NEW CANVAS WITH THE FOLLOWING NAME:
    CAN_EMP

12. SELECT A TABULAR LAYOUT AND CONFIGURE THE FORM TO DISPLAY 8 RECORDS.

13. COMPLETE THE LAYOUT WIZARD.

14. VERIFY THE FOLLOWING IN OBJECT NAVIGATOR:
    DATA BLOCK: EMP
    CANVAS: CAN_EMP

15. OPEN THE EMP DATA BLOCK PROPERTY PALETTE AND CONFIRM:
    DATABASE DATA BLOCK: YES
    QUERY DATA SOURCE TYPE: TABLE
    QUERY DATA SOURCE NAME: EMP
    INSERT ALLOWED: YES
    UPDATE ALLOWED: YES

16. SAVE THE FORM MODULE AS:
    SAIF EMP.fmb

THE EMP DATA BLOCK AND CAN_EMP CANVAS WERE CREATED SUCCESSFULLY.
